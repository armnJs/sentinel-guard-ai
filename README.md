## 🚀 Key Features & Innovation Highlights

SentinelGuard AI combines consumer-facing threat protection with enterprise SOC management:

1. ⚙️ **Enterprise Admin SOC Command Center**: Organization-wide security dashboard with department risk heatmaps (Finance, HR, DevOps), Heuristic Sensitivity sliders, Deepfake Voice Threshold controls, and DNS Firewall Sinkhole rule management.
2. 📡 **Live Global Cyber Threat SOC Feed**: Real-time scrolling ticker streaming live intercepted threat telemetry (IP geolocation, typosquatting nodes, zero-day links).
3. 🎙️ **Deepfake Voice & Audio Scam Analyzer**: Scans transcribed voicemails and audio transcripts for synthetic pitch anomalies, CEO voice clone signatures, and wire transfer coercion tactics.
4. 👁️ **Visual DOM Brand Impersonation Inspector**: Simulates a live visual browser snapshot of suspicious target pages, calculating logo similarity (e.g., 99.1% PayPal clone match) and DOM structural fingerprinting.
5. 🤖 **Interactive Sentinel AI Security Agent**: Floating zero-trust AI assistant widget powered by Google Gemini API providing real-time answer synthesis, remediation advice, and firewall configuration steps.
6. 🎯 **Multi-Vector Threat Scanner**: Heuristic pattern engine for URLs, SMS/email text, audio transcripts, and raw QR codes.
7. 🌐 **Domain Security Header Auditor**: Automated HTTP security policy inspector (`HSTS`, `CSP`, `X-Frame-Options`, `CORS`) computing overall domain grades (A+ to F).
8. 🎮 **Phish Hunt Training Simulator**: Gamified interactive scenario sandbox testing user intuition against modern AI-crafted vs. legitimate communications.

## 🏗️ Technical Architecture & Stack

- **Frontend Core**: Semantic HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 Design System.
- **Data Visualization**: Chart.js (5-Axis Radar Charting).
- **AI Models**: Google Gemini 1.5/2.0 API & Sentinel Neural Heuristic Core.
- **Typography & Aesthetics**: Google Fonts (`Outfit`, `JetBrains Mono`), FontAwesome Icons, Dark Mode Cyberpunk Glassmorphism.
