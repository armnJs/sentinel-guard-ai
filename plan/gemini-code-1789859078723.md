# Project Guidelines: What TO Do

This document outlines the strict feature requirements and best practices for developing this web application. All generated code must align with these standards to ensure a premium, production-ready user experience.

## UI & User Experience
* **Mobile-First Optimization:** Ensure a fully functional mobile menu. All touch targets must be sized correctly.
* **Interactive Feedback:** Implement clear hover states for all clickable elements and loading animations for data fetches.
* **Modern Comforts:** Include a functional dark mode toggle (saving user preference), a sticky header, and a scroll progress bar.
* **Accessibility:** Include a "skip to content" link for screen readers. Ensure high color contrast and readable typography.

## Navigation & Utilities
* **Functional Links:** Make all phone numbers (`tel:`), emails (`mailto:`), and the site logo clickable.
* **Site Helpers:** Implement a site search function, a "back to top" button, and an expandable FAQ section (accordion).
* **Smart Elements:** Add a floating contact button and utility "copy to clipboard" buttons for snippets or important text.
* **Print Ready:** Include a dedicated print stylesheet so pages format cleanly when printed out.

## Forms & Security
* **Form States:** Build distinct, beautifully styled success and error messages for all inputs. Include confirmation modals for destructive actions.
* **Authentication UI:** Include a password visibility toggle on login/signup forms.
* **Backend Security:** Secure all Python API routes and admin gates. Ensure all SQL queries are sanitized to prevent injection attacks. Do not expose raw database errors to the client.

## SEO, Polish & Tracking
* **Metadata:** Implement dynamic page titles, proper meta descriptions, and a custom favicon.
* **Content:** Display a "last updated" date on content-heavy pages. Dynamically update the copyright year in the footer. Ensure images are compressed.
* **Compliance & Analytics:** Set up a simple cookie consent banner, UTM parameter tracking logic, and boilerplate for FTC/ad compliance, Terms of Service, and Privacy Policy.
