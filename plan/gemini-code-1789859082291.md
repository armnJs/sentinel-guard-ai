# Project Constraints: What NOT To Do (The Anti-Slop Guide)

This document contains absolute prohibitions for this codebase. These constraints exist to prevent common "AI-generated" hallmarks and sloppy development practices.

## Design & Layout Sins
* **NO Horizontal Scrolling:** The layout must strictly fit the viewport width on all devices. Hide or fix any mobile overflow immediately.
* **NO Emojis as Design:** Do not insert emojis into the UI, buttons, or codebase unless explicitly instructed. Keep the aesthetic clean and professional.
* **NO Placeholder Text:** Never use "Lorem Ipsum" or generic filler text. Generate relevant, context-aware copy for all sections.

## Navigation & Link Failures
* **NO Unused Navigation:** Do not create phantom links in the header or footer that go nowhere.
* **NO Broken Elements:** Thoroughly verify that there are no broken links, dead buttons, or empty `href="#"` tags in the final output.
* **NO Default 404s:** Never rely on the server's default "Not Found" page. A custom, branded 404 error page is mandatory.

## Code & Backend Sloppiness
* **NO Open Gates:** Never leave authentication or admin routes unprotected. 
* **NO Lazy Error Handling:** Do not return generic "Server Error 500" screens without proper logging in the Python backend. Always provide the user with clear, actionable UI error states.
* **NO Unoptimized Media:** Do not load massive, uncompressed images that destroy page load speeds.
